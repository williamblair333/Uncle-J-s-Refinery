# n8n — where it would earn its place

_Status: **parked for Bill to review** · 2026-10-21. Nothing is installed. Resume with "set up
n8n" or by naming one item below._

## Shape

n8n runs **beside** Uncle J, not instead of it: the "No Hermes" decision stands, and Uncle J
stays the runtime. That's the same pattern as Ollama/ask_local.

- **Where:** a Docker service at `/opt/docker/n8n`, a `features/n8n/install.sh` and a `just` recipe.
- **Claude → n8n:** register n8n's built-in instance MCP server (public preview since 2026-04,
  `N8N_MCP_ACCESS_ENABLED=true` from v2.20). Sessions then get "run workflow X" as a tool.
- **n8n → Uncle J:** workflows call `ask_local`, `claude -p` or repo scripts through the MCP
  Client node or a command node.
- **Use it for:** inbound webhooks, OAuth SaaS connectors and browser-editable flows.
- **Don't use it for:** the 13 `uncle-j-*` crons. They work, and the scripts-first rule says
  leave them alone.

## Traps

- **Telegram:** give n8n its own bot. A Telegram trigger on the gateway's token freezes the
  gateway's `getUpdates` offset, the same two-pollers failure as before.
- **Licence:** n8n uses the Sustainable Use Licence (fair-code, not open source). Running your
  own business on it is allowed. Reselling or hosting n8n for others isn't.
- **Offline:** n8n itself is local. Every SaaS node needs the network.
- **Etsy:** there's no official node, so it's the HTTP node with OAuth2 PKCE. Shopify has a node.

## Ranked shortlist

1. **bizengine:** listings, orders, kill switch, and prior-art before publish (details below).
2. **Uncle J multi-host sync:** removes a chore Bill already dislikes.
3. **patentengine deadline guard:** cheap to build, and missing a deadline is very costly.
4. **reciepts:** email in, GnuCash out.
5. **dfir job watch:** serves the income goal directly.

Items 2 and 3 are the cheapest to try: one or two nodes each, with results in days.

## All ideas, by project

### Very good fits

- **bizengine:**
  - A spec marked `publishable: true` creates a Shopify listing (node), plus an Etsy listing
    (HTTP + OAuth2).
  - A Shopify order webhook routes the order to Slant 3D Teleport, then sends a confirmation.
  - The first node of every workflow reads `halt:`. That closes open issue #7 in the
    bizengine review: the kill switch has to be enforced, not left as a convention.
- **reciepts:** a Gmail/IMAP trigger fires on mail with an attachment. `ask_local` extracts
  vendor, date, total and lines. A python step writes a GnuCash import file (or uses piecash).
  Anything low-confidence goes to Telegram for approval.
- **larder:** on a schedule, or from a Grocy low-stock webhook, n8n reads the pantry and builds
  the meal plan, then fills the Kroger cart through its OAuth API. Checkout stays manual.
  n8n handles the token refresh.
- **proj-marketing-kit:** a rendered trailer or vertical cut gets uploaded to YouTube (node) and
  other social channels with captions. One credential store covers every platform's OAuth.

### Uncle J itself

- **Multi-host sync:** a Gitea push to `main` fires a webhook, and n8n has the pi and tc-vmh-03
  run `git pull` + `just setup` over SSH. If a host fails or is dirty, a Telegram line says so.
- **claude.ai merges:** a GitHub "PR merged" webhook makes n8n push the commit to Gitea, and the
  mirror carries it back. This replaces forwarding by hand.

### dfir (income route)

- **Job watch:** scheduled checks of job boards and RSS for DFIR/IR roles in Indianapolis.
  `ask_local` scores each posting against the dfir plan, and the good ones go to Telegram.
- **Casebook feed:** a new malware-traffic-analysis.net PCAP exercise gets downloaded and a new
  dfir-casebook stub is opened.

### patentengine

- **Deadline guard:** reminders at months 9, 11 and 11.5 of each provisional's 12-month window,
  repeating until it's marked done.
- **Prior-art check before publish:** when bizengine marks a part `publishable`, n8n runs a
  USPTO / Google Patents search first and sends the hits to patentengine triage. Publishing
  first would make the part prior art against yourself.

### voice-line

- **Voice to action:** "add coffee", "remind me Friday" and the like call an n8n webhook, which
  routes to Grocy (larder), Google Calendar or hearth. Voice-line needs only that one webhook,
  not a connector for each service.

### free-energy

- **Claim intake:** n8n watches chosen YouTube channels, forums and RSS for new device claims.
  `ask_local` extracts each claim, and a draft catalog entry is staged for Bill's review.

### hearth

- **Bills and usage:** emailed utility bills (IMAP) plus Home Assistant energy readings make a
  monthly cost per device.
- **Cross-system automations:** a Home Assistant event (node) triggers larder or Telegram.
  Rules that stay inside the house stay in Home Assistant.

### Decent, later

- **moneymaker:** a Stripe trigger feeds the spend-cap and funding checks, once real money moves.

### Not worth it

- Uncle J's crons, Klarheit (its draw-result fetch is just a schedule), deal-finder and neraas
  already work as cron + script. partikus, mafski, lc0 and immortality have no outside events
  to react to.
