# Mechanism Library

Levers for generating unconventional candidates in gttp Step 3 (class 7 and
the improvise path). Read when the candidate list is thin or every idea is a
variant of the same one. Levers generate candidates; they never exempt one
from the Step 4 kill-test or the Hard-limit route.

Use in random order. Reading 1–40 sequentially every time trains the same
grooves.

## Ideal Final Result (IFR)

Before any principle: state the outcome as if it happened by itself, with no
added system. "The roof does not degrade" — not "a device protects the roof."
Then ask what would have to be true. This is gttp class 5, "eliminate the
need", and is where the largest wins hide.

## TRIZ 40 Inventive Principles

Distilled by Altshuller's team from large-scale patent analysis. Each is a
recurring way a technical contradiction (improving X worsens Y) got resolved.
Paraphrased; canonical names and examples at
https://the-trizjournal.com/40-inventive-principles-examples/.

| # | Principle | One-line lever |
|---|---|---|
| 1 | Segmentation | Split into independent parts; make sectional; increase fragmentation |
| 2 | Taking out | Remove the interfering part, or isolate only the needed part |
| 3 | Local quality | Make structure non-uniform; give each part its own function or ideal conditions |
| 4 | Asymmetry | Replace symmetric with asymmetric; if already asymmetric, increase it |
| 5 | Merging | Combine similar objects in space, or similar operations in time |
| 6 | Universality | One part does several jobs, eliminating other parts |
| 7 | Nesting | Put one object inside another; pass one through a cavity in another |
| 8 | Anti-weight | Offset weight with lift, buoyancy, or aero/hydrodynamic force |
| 9 | Prior counter-action | Pre-load the opposite stress before the working stress arrives |
| 10 | Prior action | Do all or part of the work in advance; pre-position for convenience |
| 11 | Cushion in advance | Add countermeasures ahead of an unreliable step |
| 12 | Equipotentiality | Change conditions so nothing needs raising or lowering |
| 13 | Inversion | Do the opposite; fix the moving part and move the fixed one; flip it over |
| 14 | Spheroidality | Replace flat/linear with curved/rotary; use rollers, balls, spirals, centrifugal force |
| 15 | Dynamics | Let it self-adjust per stage; make rigid parts movable or interchangeable |
| 16 | Partial or excessive action | If 100% is hard, aim for slightly less or slightly more |
| 17 | Another dimension | Move in 2D/3D instead of a line; multi-layer instead of single; tilt or turn on side |
| 18 | Mechanical vibration | Oscillate; raise frequency; use resonance; piezo; ultrasonic + EM field |
| 19 | Periodic action | Replace continuous with pulsed; change the frequency; use the pauses |
| 20 | Continuity of useful action | Run at full capacity without pauses; remove idle motion |
| 21 | Skipping | Do the harmful or risky step very fast |
| 22 | Convert harm to benefit | Use the harmful factor; cancel one harm with another; amplify until harmless |
| 23 | Feedback | Add feedback; if present, reverse it |
| 24 | Intermediary | Use a carrier object; temporarily attach something easy to remove |
| 25 | Self-service | Make the object maintain itself; use waste material or energy |
| 26 | Copying | Use a cheap copy instead of the fragile original; use an image or scaled copy |
| 27 | Cheap short-lived object | Many disposable cheap parts instead of one durable expensive one |
| 28 | Replace mechanical system | Use optical, acoustic, electrical, magnetic fields instead of mechanics |
| 29 | Pneumatics and hydraulics | Replace solid parts with gas or liquid; inflate; hydrostatic cushion |
| 30 | Flexible shells and thin films | Replace rigid construction with membranes; isolate with film |
| 31 | Porous materials | Make it porous or add porous inserts; pre-fill pores with something useful |
| 32 | Color changes | Change color or translucency; add tracers to see hidden processes |
| 33 | Homogeneity | Make interacting objects from the same or similar material |
| 34 | Discarding and recovering | Discard/dissolve/evaporate spent parts; restore depleted parts in place |
| 35 | Parameter changes | Change state, density, flexibility, temperature, concentration |
| 36 | Phase transitions | Exploit volume change or heat released/absorbed during phase change |
| 37 | Thermal expansion | Use expansion/contraction; pair materials with different coefficients |
| 38 | Strong oxidants | Enriched air → oxygen → ionized oxygen; ionizing radiation |
| 39 | Inert environment | Replace atmosphere with inert gas; operate in vacuum |
| 40 | Composite materials | Replace homogeneous material with a composite |

## Additional levers (not TRIZ)

| Lever | Prompt |
|---|---|
| Extremes | What if 10× more / 10× less / zero of this component? |
| Time shift | Solve it earlier, later, or only when needed instead of always |
| Place shift | Move the problem to where it's cheap to solve |
| Reframe the failure | If the thing will fail anyway, make failure cheap and fast instead of rare |
| Steal from another domain | Where else does "seal a hole of the wrong shape" / "shed water but pass vapor" / "hold under tension" get solved? Marine, dental, aerospace, agriculture, medicine, packaging |
| Property strip | Describe every on-hand object by shape, ID/OD, rigidity, chemistry, thermal limits — never by its label |
| Do the user's labor math | Any "free" solution that eats hours is not free; price the hours |
| Contact vs stood-off | A protective layer touching the protected surface traps moisture, heat, and debris; the stood-off version (air gap) usually keeps the benefit and drops the trap |
| Check the fit geometry | A shape's worst-case dimension is its diagonal, not its flats: a square of width W needs a round bore ≥ 1.41W and a 12-point socket of about 1.22W (an 8-point socket is made for squares at W). Compute fits; don't assume "same size" |
| Functional fixedness check | If you keep naming an item by its label ("PVC cap"), restate it by properties ("rigid dome, 1.05 in ID") and ask what else it is |
